## 💻 Sobre o projeto

<!-- EXPLICA O MOTIVO DO PROJETO -->
Fintech é um projeto criado para o treinar meus conhecimentos no curso de Front End.

Fintech é um projeto desenvolvido no curso de Desenvolvimento Front-End para praticar HTML e CSS, com foco em semântica, organização do código e boas práticas de desenvolvimento. O projeto busca aplicar conceitos essenciais da construção de interfaces web modernas e responsivas.

## 💪 Como contribuir para o projeto

1. Faça um **fork** do projeto.
2. Crie uma nova branch com as suas alterações: `git checkout -b my-feature`
3. Salve as alterações e crie uma mensagem de commit contando o que você fez: `git commit -m "feature: My new feature"`
